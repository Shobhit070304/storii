# Storii

An archive of lived experience. Storii collects questions and answers written by people who were there — real lessons, quiet habits, and honest reflections.

## Tech Stack

- **Framework**: Vite + React 19 + TypeScript
- **Routing**: React Router v7 (`react-router`)
- **Styling**: Tailwind CSS v4 + Shadcn UI primitives
- **Motion & Icons**: Framer Motion & Lucide Icons
- **Data & State**: Reactive client-side store with `localStorage` persistence

## Running the App

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

No backend servers, cloud databases, or authentication setup required.

## Key Features

- **The Feed**: Browse questions with real-time search, sorting (Newest, Most answered, Open), and category filters.
- **Categories**: Six editorial shelves (`Work & Career`, `Money`, `Relationships`, `Health & Body`, `Home & Moving`, `Learning`).
- **Question Details**: View experience-based answers with verified context lines ("how I know").
- **Ask & Answer**: Ask questions or share your experience directly, signed or anonymous.
- **Your Desk**: Track your contributions, questions asked, and experiences shared.
